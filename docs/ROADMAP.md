# Roadmap

Stages are sequential unless noted; each ends with tests, documentation and a reviewed PR.

| #   | Stage                                                        | Depends on     | Main content                                                                                                                                                                                                                                                                                                                                                |
| --- | ------------------------------------------------------------ | -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **Foundation** (this PR)                                     | —              | Project structure, tooling, CI, env validation, i18n (5 languages), UI shell, identity/tenancy/permission schema, authorization guard, money module                                                                                                                                                                                                         |
| 2   | **Authentication & sessions** (branch `feat/stage-2-auth`)   | 1              | Better Auth (see [auth/AUTHENTICATION.md](auth/AUTHENTICATION.md)); email/password (scrypt), Google sign-in, email verification, secure password reset, DB-backed sessions with listing/revocation, TOTP 2FA (mandatory for owner/admin roles) with recovery codes, rate limiting on auth endpoints, auth audit events, CSRF review                         |
| 3   | **Company & team management**                                | 2              | Create/switch company, company profile per country, invitations, role assignment and custom roles UI, last-owner protection, audit log viewer, PostgreSQL RLS as defence in depth                                                                                                                                                                           |
| 4   | **Master data**                                              | 3              | Customers, suppliers, products/services, units; validation of registration/VAT number formats (formats only — no claims of legal validation)                                                                                                                                                                                                                |
| 5   | **Exchange rates**                                           | 3              | Reference source integration (provider to be confirmed, with provenance and date), manual correction with audit, rate snapshots                                                                                                                                                                                                                             |
| 6a  | **Document foundation** (branch `feat/documents-foundation`) | 1              | Unified data model, totals and tax summary, numbering series, validation, immutable issued documents with snapshots, credit notes / delivery notes / proforma conversion / replacements, multilingual PDF rendering, PDF import with review and duplicate detection — see [documents/DOCUMENT-SYSTEM.md](documents/DOCUMENT-SYSTEM.md)                      |
| 6b  | **Documents UI & API**                                       | 2, 3, 4, 5, 6a | Draft editor, import review screen, PDF download, tax-category and numbering settings, company profile as seller/bank source, payment status, historical import with original numbers. Country-specific tax rules and mandatory content only after verification against official sources per country and effective date; e-invoicing formats where required |
| 7   | **Notifications**                                            | 3              | In-app, email, Telegram; urgent vs digest; routing by role/responsibility; background worker                                                                                                                                                                                                                                                                |
| 8   | **Inventory, costing, import costing, production**           | 4, 6           | Stock movements, valuation method (to be decided with accountants), landed costs, bills of materials                                                                                                                                                                                                                                                        |
| 9   | **Subscriptions**                                            | 2, 3           | Stripe (test mode first); Basic €6.99, Pro AI €12.99, Business €19.99; 2-day trial with **no automatic paid conversion without explicit consent**                                                                                                                                                                                                           |
| 10  | **Claude API assistant**                                     | 6, 9           | Server-side only; permission-checked tools; any action with financial consequences requires explicit authorization and confirmation; audit trail                                                                                                                                                                                                            |
| 11  | **Accounting integrations & exports**                        | 6              | Per-system adapters, bidirectional sync only where the external API supports it; idempotency and conflict handling                                                                                                                                                                                                                                          |
| 12  | **Payroll**                                                  | 3              | Only after country-specific rules are verified with official sources and professionals                                                                                                                                                                                                                                                                      |
| 13  | **Analytics**                                                | 6, 8           | Per-currency reporting                                                                                                                                                                                                                                                                                                                                      |
| 14  | **Launch readiness**                                         | all            | Backups + restore drills, monitoring/alerting, error tracking, load and security testing, privacy (GDPR) processes, native-speaker translation review                                                                                                                                                                                                       |
